# 套餐资费速查（机器人口径）

来源：《2026年新进人员入职培训课件》市场经营部 2026-03，产品政策部分。
这份是给机器人和维护者看的**判单口径**，不是完整政策；政策变了改这里，同时改 `config.yaml` 的 `agent.context`。

## 1. 融合宽带（主战场，「新增/存量」只针对这类）

| 档位 | 带宽 | 说明 |
|---|---|---|
| 399 | 2000M（需 FTTR） | 美好家 5G-A 尊享，7 副卡 |
| 299 | 2000M（需 FTTR） | 美好家 5G-A |
| 239 | 2000M（需 FTTR） | 美好家 5G-A，4 副卡 |
| 199 | 1000M | 美好家 5G-A，4 副卡 |
| 169 | 500M，有条件升 1000M（加 10 元云盒/AI/智屏/FTTR 后 1 元提速） | 中套 |
| 139 | 500M | 中套 |
| 99 | 300M | 低档 |
| 79 | 200M，有条件升 300M | 低档 |

- **中高套 = 139 及以上**（中套 139/169，高套 199/239/299/399）。79、99 不算。
- **千兆/500兆 = 139 及以上**（139 起就是 500M）。只对新增记；存量升档原表填法不一致，标待核对。
- **149 / 179 / 209 / 249 这种数不是档位**，是「档位 + 10 元附加」写成了总额：149 = 139+10。判档位按去掉附加后的基础档。
- 129 是老套餐（课件：网龄提速表有【129,169）档、存量政策有「129元套餐升级139+10」），只在存量单的「前」档位里出现。
- 亲情宽带：按 79/99 融合算，新增宽带 1，不是中高套。

## 2. 附加项（写在「+」后面的，不是档位）

| 写法 | 是什么 | 月费 |
|---|---|---|
| +10 / 云盒 / 轻云盒 | 云盒 | 10 |
| +10 / AI / 视联网 / AI视联网 | AI 视联网 | 10 |
| +9.9 / AI守护 / 摄像头 | AI 守护包（摄像头） | 9.9 |
| +25 / +10 / 智屏 / 天翼智屏 | 智屏 | 25 或 10 |
| +25 / FTTR / R / 光纤到房间 | FTTR（一主一从） | 25 |
| +1 / 提速 / 网龄提速 | 提速到 300M/500M/1000M | 1 |
| +15 小合约 / +10 小合约 | 终端小合约（摄像头等） | 10~15 |
| 副卡 | 副卡，1 元可领 20G | 1 |

- **+10 不一定是云盒**，可能是 AI 视联网或智屏 —— 所以云盒/AI/智屏这一列只信晒单里「是否加载」字段，不从「+10」推。
- **「R」= FTTR**（「必选 R」「兑换 R」都是指 FTTR）。
- 积分：新增 = 档位 + 附加（139+10 → 149 分）；升档 = 差价 + 附加（169改199 → 30 分）；纯续签 = 0；纯加装 = 附加值。

## 3. 单宽带 / 副宽（算新增宽带，不算中高套）

| 类型 | 档位 | 带宽 |
|---|---|---|
| 包月单宽 | 198 / 138 / 98 / 68 | 1000M / 500M / 300M / 200M |
| 包年单宽 | 1990 / 1390 / 990 / 690 / 390 | 同上；390 是 50M |
| 副宽 | 60 元/月（500M，239 及以上千兆用户）；38 元/月（300M，139 及以上融合用户） | |
| 度假市场 | 390 包年（100M）/ 780 包年（200M） | 仅 6-8 月 |

- 副宽是主宽带之外**独立的一条新增宽带**，没有自己的档位，不计中高套。「新增199+副宽」= 2 个新增宽带、1 个中高套。
- 包年单宽的价值积分原表没有先例，先按数字记。
- 单宽的「千兆/500兆」按带宽查表：138 单宽、198 单宽、1390 包年、1990 包年记 1；68/98 单宽、390/690/990 包年记 0（390 包年只有 50M）。

## 4. 移动号卡（一律记「单C」，不算宽带、不算中高套）

| 档位 | 内容 | 预存 |
|---|---|---|
| 19 | 200 分钟 + 10G 通用 + 20G 重庆 | 100 |
| 39 | 300 分钟 + 25G + 45G | 120 |
| 59 | 500 分钟 + 40G + 60G，可加 1 张副卡 | 120 |
| 99 | 700 分钟 + 60G + 75G | 200 |
| 159 | 700 分钟 + 100G + 75G | |

- 群里叫法：山城卡、号卡、单C、5G单C、携转（携号转网，把别家号转过来）、异网卡、副卡。
- **橙分期也是号卡**（手机需求）：59返30、99返55、159返100、5G-A 199/299/399 橙分期。
  「橙分期399」是 399 档的**号卡**，不是 399 宽带 —— 模型最容易在这里判错。
- 橙分期的价值积分 = 月费 − 月返（59返30 → 29 分；99返55 → 44；159返100 → 59；199 → 109；299 → 154；399 → 199）。
- 购机包 50/100/200/300：到期用户续约办的，不是新增。

## 5. 存量的叫法（全部 is_new = false）

| 词 | 意思 | 记法 |
|---|---|---|
| 提值（课件「存量权益政策」的口径） | **提值 = 续约后总和 − 续约前总和**，课件按 [0,30) / [30,50) / 50+ 分档配权益 | 机器人存量单的积分就是提值 |
| 高迁 / 改 / 升 / 提值（139改199、79改139+10、109提值169、169提值60、99+10） | 总和变大 | 存量，长续约 1，积分 = 提值（60 / 70 / 60 / 60 / 10） |
| 平迁 / 续约 / 续签 / 只写档位（139、199续签、139改129+10） | 总和不变（含换同价新版套餐） | 存量，长续约 1，积分 0 |
| 负迁 / 降档（139改99、139改99+10 = 139→109） | 总和变小 | 存量，照记清单但长续约 0、积分 0，备注「降档不计业绩」 |
| 高迁 / 拆机维系（没写原档位，如「199高迁」） | 算不出提值 | 存量，长续约 1，积分待核对（标黄） |
| 加装 / 融合 / 叠加（云盒、+10，没有档位数字） | 原套餐上加云盒/AI/智屏/FTTR | 存量，不算长续约，积分 = 附加值 |
| 返费用户续约（原 169 返 60 实缴 109，续约后不返了） | 前 = 109，后 = 169 | 写成「109提值169」或「169提值60」，提值 60 |
| 提速 / 网龄提速 / 1元提速 | 1 元/月提速 | 存量，不计数 |

## 6. 权益金（不进清单，只是看到时别当成套餐档位）

699 / 500 / 1200 / 1298 / 750 / 998 / 1047 / 1296 这些是权益金币数，不是档位。

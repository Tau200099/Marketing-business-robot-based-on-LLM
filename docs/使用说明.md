# 📣 业绩机器人使用说明

（可以整段复制发到群里）

## 一、文字晒单：在群里 @机器人 发

1. 在群里 @业绩机器人，按模板发：

```
支局：
业务类型：
办理套餐：
业务号码：
价值积分：
是否加载AI：
是否加载云盒：
是否加载智屏：
是否加载FTTR：
号卡数量：
揽收人：
```

2. 机器人点赞就是记上了。格式不对它会提示。发错了直接重发一遍，按最新一条算，不会重复计。
3. ⚠️ 单聊机器人发晒单**不记单**，一定要在群里 @ 它。

## 二、打卡照：群里发一份，再单聊机器人发一份

1. 用「今日水印相机」拍。「工作内容」如实填，办成了业务就写业务，比如「新增139」「129改169」。
2. 先把照片发到群里，**不用 @**。
3. 再打开和机器人的**单聊**，把同一张照片发给它。机器人回「打卡已记：9.28 14:30 下午｜现场拦截」就记上了。
4. 同一张照片发两次只算一次。不是水印相机拍的不算。晚上 21:00 以后拍的不计入统计。

✅ 有效打卡：拦住路人或在摊位上介绍；电视上演示云盒菜单，或拿着设备讲解；把蓝色板夹、资费单拿给客户看；
给客户算账，或手机上正在办理业务；拍异网资费界面。

❌ 无效打卡：只拍到人在屋里或店里聊天，没有展示任何东西；画面里没有人。

## 三、打卡时段

上午 8:30–11:50，下午 14:00–18:00，晚上 18:00–21:00。时段之间拍的算到下一个时段。

## 四、其他常用

- 群里 @机器人「通报」：看当前业绩
- 群里 @机器人「打卡通报」：看本时段各小组打卡情况
- 群里 @机器人 直接问，比如「今天新盛几单」
- 单聊机器人「晒单表格发我」「打卡表格发我」「打卡表格 9.25」：拿到 Excel

## 五、说明

- 不在活动期间时，晒单和打卡都不记录，机器人会提示。
- 对打卡判定结果有异议，请找管理员。

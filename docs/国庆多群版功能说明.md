## 一、三个群各管什么

| 群 | 谁在里面晒单 | 机器人往这里发什么 |
|---|---|---|
| 城区支局营销活动群 | 城区活动人员 | 城区活动晒单通报、城区活动打卡通报 |
| 农村支局营销活动群 | 农村活动人员 | 农村活动晒单通报、农村活动打卡通报 |
| 綦江分公司秋促营销攻坚群 | 所有人都可以（主要是没参加活动的人） | 支局总表、城区支局打卡通报、农村支局打卡通报（附支局长到场） |

- ✅ 例：11:30 攻坚群收到支局总表 + 城区支局打卡 + 农村支局打卡
- ❌ 反例：城区群里永远不会出现农村的数据、也不会出现「恭喜赶水支局」

## 二、名册和「这个人是谁」

**四张名册**，管理员单聊先发一句说明是哪张，2 分钟内再发 Excel：
`城区支局名册` / `城区活动名册` / `农村支局名册` / `农村活动名册`

| 名册 | 列（【假设】，等你给实际格式） |
|---|---|
| 支局名册 | 姓名、支局、是否支局长 |
| 活动名册 | 姓名、分组、战区（和现在一样） |

**每个人归成一类**（企微账号 → 名册里的姓名 → 类别）：

| 类别 | 条件 |
|---|---|
| 城区活动人员 | 在城区活动名册里 |
| 农村活动人员 | 在农村活动名册里 |
| 城区非活动人员 | 在城区支局名册、不在活动名册 |
| 农村非活动人员 | 在农村支局名册、不在活动名册 |
| 未识别 | 账号对不上任何名册 |

- ✅ 例：杨桐在城区活动名册 → 城区活动人员
- ✅ 例：某人只在农村支局名册 → 农村非活动人员
- ❌ 反例：账号 `echo.` 对不上名字 → 未识别；机器人单聊提醒管理员「这些账号认不出：echo.」，补进 `userid_map` 或名册后，他之前的单和打卡**自动重新归类**
- ❌ 反例：活动名册里的人不在本区支局名册 → 导入时提醒「这 3 个人不在城区支局名册里」（还是导入，只提醒）

## 三、晒单：按人记，一单只记一次

在**任何一个群** @机器人 晒单 → 认人 → 记一条（带上类别、落地支局）→ 各张表按类别取数。

| 谁 | 在哪个群晒 | 进城区活动表 | 进农村活动表 | 进支局总表 |
|---|---|---|---|---|
| 城区活动人员 | 城区群 | ✅ | | ✅ |
| 城区活动人员 | 攻坚群 | ✅ | | ✅ |
| 农村活动人员 | 农村群 / 攻坚群 | | ✅ | ✅ |
| 非活动人员 | 攻坚群 | | | ✅ |
| 非活动人员 | 活动群 | ❌ 不进 | ❌ 不进 | ✅ |
| 未识别 | 任何群 | ❌ | ❌ | ✅（按晒单里写的支局，标黄） |

- ✅ 例：农村活动人员在攻坚群晒了一单 → 农村活动表、支局总表都有这单
- ❌ 反例：城区非活动人员在城区群晒单 → 城区活动通报里**没有**这单，只在总表里
- ❌ 反例：同一单（同一个业务号码）在两个群都发了 → 只算一次，后发的覆盖先发的
- 回复：在发单的那个群点赞。【假设】「支局战报」（恭喜 XX 支局第 N 单）只在活动群里发、只数本区的单；攻坚群里的单只点赞不播战报

## 四、活动群晒单通报（城区、农村各发各的）

- ✅ 例：11:30 农村群收到的通报只有农村的战队 / 小组

## 五、支局总表（攻坚群）

按你给的模板：分类 | 支局 | **当日**（五项各 目标 / 完成值 / 进度 + 综合）| **累计**（同左）| 同类排名 | PK激励；末行合计 + 宽带折算注释。17 个支局按一类 / 二类 / 三类排列。

### 5.1 算法

1. 每一单按「六、五项指标」算出 宽带 / 中高套 / 千五 / 套包 / 单号卡 各多少
2. 算给哪个支局：晒单里写的**落地支局**；揽收人的支局不一样时，揽收人支局 60%、落地支局 40%（【假设】你还没明确回）
3. 进度 = 完成值 ÷ 目标；**千五、套包、单号卡最多算 130%**，宽带、中高套不封顶
4. 综合完成进度 = 宽带进度×25% + 中高套×30% + 千五×20% + 套包×15% + 单号卡×10%
5. 当日 = 今天的单；累计 = 10.1 起到现在
6. 同类排名按**累计**综合进度，同类里从高到低
7. PK激励按当前名次填；综合进度 >100% 但排在输的一边，标「（分公司出资）」
8. 合计：目标、完成值各自加总，进度用加总后的数算

### 5.2 算一个支局（目标是编的，只为演示）

通惠（一类）累计：

| 指标 | 目标 | 完成 | 进度 | 计入综合 |
|---|---|---|---|---|
| 新增宽带 | 20 | 12 | 60% | 60% × 25% = 15 |
| 中高套 | 15 | 18.3 | 122%（不封顶） | 122% × 30% = 36.6 |
| 千兆/500兆 | 20 | 30 | 150% → **按 130%** | 130% × 20% = 26 |
| 套包 | 30 | 25.5 | 85% | 85% × 15% = 12.75 |
| 单号卡 | 10 | 16 | 160% → **按 130%** | 130% × 10% = 13 |
| **综合完成进度** | | | | **103.35%** |

一类 5 个支局按累计综合进度排：通惠第 2 → PK激励 **+1500**。
- ❌ 反例：通惠如果排第 4、综合 103.35% → 「−1500（分公司出资）」
- ❌ 反例：9.30 晒的单、10.8 晒的单都不算进累计
- 【待定】当日目标：附件一有没有每日目标，还是总目标 ÷ 7
- 【待定】新盛：人员在城区群、PK 算二类？（按模板它排在二类里）

### 6.2 各项规则要点

  【假设】名单里会标出哪些人在做小区 / 场镇营销，这些人的单 ×1.1 —— 等名单来了再对

## 八、支局长到场（人脸，只在攻坚群）

- 17 个支局长每人录 1–3 张正脸（管理员单聊「录入人脸 张三」+ 照片）；支局长名单写明谁是哪个支局的
- **每一张**单聊打卡照（不管谁发的）都和 17 个支局长比对；认出谁，就记在这条打卡上（按水印时间）
- 三个时段：09:00–11:50、14:30–18:00、18:00–20:50；时段里任意一张照片认出 = 该时段到场
- 攻坚群的打卡通报末尾附一行：「支局长到场（下午）：通惠✅ 古南✅ 文龙❌ …」，每半小时更新，时段结束那次为准
- 管理员单聊「补记到场 文龙 下午」→ 文龙下午改成到场（通报里标「人工补记」）

- ✅ 例：11:05 小王（通惠组员）发的照片里认出通惠支局长 → 通惠上午✅（不是支局长本人发的也算）
- ✅ 例：18:00 整的照片 → 算晚上（和打卡时段一样，首尾相接的整点算下一段）
- ❌ 反例：支局长只露背影 / 侧脸没认出 → 通惠❌，管理员核实后「补记到场」
- ❌ 反例：12:30（午休）、08:45（9 点前）的照片 → 不算任何时段
- ❌ 反例：照片里的客户、其他同事 → 比完就丢，不记任何东西

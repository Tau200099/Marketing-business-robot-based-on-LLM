# 表情包图库

把图片直接丢进这个目录就行，机器人会自动扫到。

- 支持格式：png / jpg / jpeg / gif
- 建议 10 张左右，太少会看着重复
- 单张别太大，建议 500KB 以内（上传要转 base64，会膨胀约 1/3）

## 工作方式

- 每次点赞后随机挑一张发出去
- 最近用过的 5 张不会再挑（可在 config.yaml 的 `stickers.avoid_last` 调）
- 默认只在【新增单】后面配图，续约不配（`stickers.only_new`）

## 关于 media_id

企微发图要 media_id，只能通过长连接上传获得，**有效期 3 天**。
机器人会自动缓存到 `stickers_cache.json`，过期自动重传，不用管。

图片换了内容但文件名没变也能识别（按内容指纹判断），会自动重传。
